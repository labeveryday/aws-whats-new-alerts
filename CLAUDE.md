## Project Overview

AWS What's New Alerts is an AI agent that automatically generates daily email newsletters about AWS announcements, with a focus on AI/ML-related updates. The system uses AWS Bedrock AgentCore with Strands agents to fetch, filter, and format AWS news, then distributes it via SNS/SQS infrastructure.

## Development Environment

**Python Virtual Environment**: Always use the `.venv` virtual environment when executing Python code:
```bash
source .venv/bin/activate  # Activate venv before running any Python commands
```

## Architecture

The project has two main components:

### 1. Newsletter Infrastructure (`backend/`)
SNS/SQS-based email delivery system with two deployment options:

- **Boto3 deployment**: Direct Python script using boto3 (`deploy_boto3.py`)
- **CDK deployment**: Infrastructure as code using AWS CDK (`app.py`, `newsletter_stack.py`)

Key resources:
- SNS topic for email distribution
- SQS queue for delivery tracking
- Dead letter queue for failed messages
- IAM roles with least-privilege permissions

### 2. AI Agent (`deployment/`)
Bedrock AgentCore agent that generates newsletters:

- **agent.py**: Main agent application using Strands framework
  - Fetches AWS news from https://aws.amazon.com/new/
  - Filters for AI/ML-related announcements (default) or broader coverage (on request)
  - Processes user-specified time frames (last 24h, week, month, etc.)
  - Uses AgentCore memory to avoid duplicate processing
  - Formats professional newsletters with numbered announcements
  - Publishes via SNS using custom tools

- **tools/**: Strands agent tools
  - `sns_tools.py`: SNS operations (create topics, publish messages, manage subscriptions)
  - `sqs_tools.py`: SQS operations (queue management)

## Common Commands

### Backend Infrastructure

```bash
# FULL STACK DEPLOYMENT (Recommended - includes AgentCore Memory)
cd backend
python deploy_full_stack.py --email your-email@example.com    # Deploy everything + generate .env
python deploy_full_stack.py --cleanup                          # Remove all resources

# Legacy Boto3 deployment (SNS/SQS only, no memory)
cd backend
python deploy_boto3.py --email your-email@example.com    # Deploy infrastructure
python deploy_boto3.py --send-test "Subject" "Message"   # Send test newsletter
python deploy_boto3.py --check-status                     # Check delivery status
python deploy_boto3.py --cleanup                          # Remove all resources

# CDK deployment (alternative IaC approach)
cd backend
npm install -g aws-cdk                                    # Install CDK (first time)
cdk bootstrap                                             # Bootstrap CDK (first time)
cdk deploy --context email=your-email@example.com        # Deploy stack
cdk destroy                                               # Destroy stack
```

### Agent Development

```bash
# Run agent locally
cd deployment

# Invoke deployed agent
python invoke_agent.py --prompt "Generate newsletter for last week"
```

### Environment Configuration

The `.env` file is **auto-generated** by `deploy_full_stack.py` and contains:
```bash
# Auto-generated by deploy_full_stack.py
SNS_TOPIC_ARN=arn:aws:sns:region:account:topic-name    # SNS topic for email delivery
SQS_QUEUE_URL=https://sqs.region.amazonaws.com/...     # SQS queue URL
BEDROCK_AGENTCORE_MEMORY_ID=memory-id                   # AgentCore memory ID
AWS_REGION=us-east-1                                     # Deployment region
AWS_ACCOUNT_ID=123456789012                             # AWS account

# Add manually after agent deployment:
AGENTCORE_ARN=arn:aws:bedrock-agentcore:...             # Deployed agent ARN (from agentcore launch)
```

**Note:** Only `AGENTCORE_ARN` needs to be added manually after running `agentcore launch`.

## Key Technical Details

### Agent Behavior
- **Default mode**: AI/ML-focused announcements from last 24 hours
- **User override**: Responds to time frame requests ("last week", "last 3 days", etc.)
- **Content filter**: Only processes articles ≥ 2022-10-01 (set in CUTOFF_DATE)
- **Memory integration**: Uses AgentCore memory to prevent duplicate processing
- **Newsletter format**: Professional ASCII-bordered layout with numbered announcements and statistics

### Tools Auto-Loading
The agent uses `load_tools_from_directory=True`, which automatically loads all `@tool` decorated functions from `deployment/tools/`. When adding new tools, simply place them in the tools directory with proper `@tool` decorator.

### SNS/SQS Integration
- SNS topic delivers emails to subscribers
- SQS queue receives delivery status notifications
- Dead letter queue captures failed messages after 3 retries
- IAM role grants SNS permission to write to SQS only

### CDK Stack Components
`NewsletterStack` (in `newsletter_stack.py`) creates:
- SQS queues with DLQ configuration
- SNS topic with delivery status tracking
- IAM role with least-privilege policies
- Lambda custom resource for SNS delivery status configuration
- CloudFormation outputs for all resource ARNs
